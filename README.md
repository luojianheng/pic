# 手绘工坊 HandDrawn Lab

照片一键转四种手绘风格 —— 纯前端、零后端、**图片不出本机**。

🔗 在线使用：**https://luojianheng.github.io/pic/**

---

## ✨ 功能

### 四种手绘风格

| 风格 | 算法要点 |
|:---|:---|
| **极简线条速写** | Sobel 梯度 + 形态学平滑 + **双阈值分级**（主线浓墨 / 辅线淡墨），线条主次分明 |
| **铅笔素描** | 颜色减淡（Color Dodge）+ S 型层次曲线 + Sobel 轮廓加深，碳笔质感 |
| **水彩画** | **保边晕染**（仅在亮度接近处混合）+ 色阶量化 + **湿边积色**（边缘自然加深） |
| **油画笔触** | **Kuwahara 四象限最小方差滤波** + 色彩对比增强 + 边缘深描，厚涂肌理 |

### 交互

- **强度调节**：10–100 无级滑块，实时重绘
- **原图对照**：双 Canvas 并排对比
- **我的作品**：一键存入本地作品库，画廊浏览 / 大图预览 / 下载 / 删除 / 清空
- **导出**：编辑区 PNG 无损导出；作品库 JPEG 导出
- **拖拽上传**：支持 JPG / PNG / WebP，≤20MB

## 🔒 隐私

图片**全程在本机浏览器内处理，不上传任何服务器**（无后端、无第三方请求）。

作品保存在**你这台设备**的浏览器数据库（IndexedDB）里 —— 换设备、换浏览器或清空浏览器数据会丢失，请及时下载备份。

---

## 🛠 技术

单文件 `index.html`，无依赖、无构建步骤、无外部请求：

- **图像算法**：Canvas 2D + `Float32Array`/`Uint8ClampedArray` 手写实现（灰度、Sobel、可分离盒式模糊、Kuwahara）
- **本地存储**：IndexedDB（库名 `handdrawn-lab`，对象仓 `works`），存储缩略图 + 完整作品 Blob
- **无障碍**：语义化标签、`aria-selected`/`aria-pressed`/`aria-label`、键盘可达（Tab/Enter/Space/Esc）、`prefers-reduced-motion` 适配
- **视觉约束**：标题 `text-wrap: balance`、数字 `font-variant-numeric: tabular-nums`、无渐变/发光装饰、动效仅 `transform`/`opacity` 且 ≤200ms
- **性能**：处理宽度上限 1200px；重绘前先渲染加载态再计算（主线程被占满时界面仍有反馈）

实测单次重绘耗时（Node 22，1200×900 合成图，强度 50%）：

| 风格 | 1200×900 | 1200×1600 |
|:---|---:|---:|
| 极简线条速写 | 0.68s | 1.18s |
| 油画笔触 | 1.26s | 2.17s |
| 铅笔素描 | 1.96s | 3.20s |
| 水彩画 | 2.37s | 4.11s |

> 注：这是把算法抽出来在 Node 22 下跑的纯计算基准（不含 Canvas 绘制），仅用于判断四种风格的相对开销——**水彩最重、速写最轻**，故重绘前统一加加载态。
